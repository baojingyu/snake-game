# 指尖小蛇 · Snake

单文件 HTML5 贪吃蛇（跟随手指/鼠标滑动），零外部依赖、零 CDN，离线也能玩。

- 在线（GitHub Pages，国内实测可访问）：https://baojingyu.github.io/snake-game/
- 备用（jsDelivr）：https://cdn.jsdelivr.net/gh/baojingyu/snake-game@main/index.html
- 本地：`index.html` 直接用浏览器打开即可

主题可用 `?theme=` 切换：`candy`（默认）/ `forest` / `ocean` / `space` / `flat`；
`?autostart=1` 自动开始。
